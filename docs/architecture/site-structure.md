# 02. 内容结构与路由表 (Site Structure & Routing)

## 1. 核心导航栏设计

顶部导航将承载所有主要功能模块。此栏在 PC 端将作为通顶固定存在，并随着向下滚动自动切换为轻量化模式；而在移动端，它将被收纳进折叠式汉堡菜单中。

为满足用户直观查找的诉求，站点设定以下主要板块：

1. **首页 (Home)**
2. **查询与预定 (Check Rates & Reservations)**
3. **图片与视频 (Photos & Videos)**
4. **位置 (Location)**
5. **优惠精选 (Offers)**
6. **酒店概览 (Hotel Overview)**
7. **联系我们 (Contact Us)**

## 2. 前端路由表映射

我们基于 `next-intl` 实现国际化架构，默认支持 `/[locale]/...` 路由格式。

| 区块名称       | 核心路由路径                  | 页面定位 / 功能说明                                                                 |
| :------------- | :---------------------------- | :---------------------------------------------------------------------------------- |
| **首页**       | `/` (`/zh`, `/en`)            | 站点入口，呈现品牌概念视频、特色区域缩影等。                                        |
| **查询与预定** | `/booking` 或 `/reservations` | 预订主面板，整合客房检索、日期选择与空房展示系统。                                  |
| **图片与视频** | `/gallery`                    | 品牌资产陈列：展现别墅、套房、海岛全景的高分辨率多媒体图集。                        |
| **位置**       | `/location`                   | 提供互动式地图映射、如何抵达 (Getting Here) 的航班和专属快艇指引。                  |
| **优惠精选**   | `/offers`                     | 所有营销促销包页面，例如 `提前预订特惠`、`康养套餐`等。                             |
| **酒店概览**   | `/overview`                   | 关于 **美丽度假酒店 MEILI RESORT HOTEL** 的全面说明：如服务等级、休闲及特色餐饮等。 |
| **联系我们**   | `/contact-us`                 | 客服表单、各业务接洽方式列表。                                                      |

_(注：为保证交互流畅度，顶部吸顶导航在 PC 和移动端需实现“立即预订”按钮的常驻)_。
