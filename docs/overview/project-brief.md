# 01. 项目概览 (Project Overview)

## 1. 酒店基础信息

- **中文名称**：美丽度假酒店
- **英文名称**：MEILI RESORT HOTEL
- **对标/参考平台**：[四季酒店波拉波拉度假村](https://www.fourseasons.com/zh/borabora/)
- **项目愿景**：打造兼具奢华感、高度视觉冲击力及 SEO 友好的官方预订网站，传达“美丽度假酒店”静谧感与高端定位。

## 2. 核心技术栈

- **框架**: Next.js (App Router, React + TypeScript)
- **多语言机制**: `next-intl` (支持 `/zh` 及 `/en` 路由响应)
- **视觉/UI**: Tailwind CSS + shadcn/ui
- **动画/交互**: Framer Motion + Lenis 柔性滚动
- **表单与状态**: React Hook Form + Zod，接入 HMS 预订接口

## 3. 核心设计语言与规范

- **主题主色调**: `#003865` (一种深邃、高雅的深蓝色，传达海洋与奢华的氛围)。
- **辅助色/文字色**: 经典的黑白与浅灰色，配合淡金色作为交互强调色。
- **排版策略**: 以高清图片及全屏视频为核心驱动，现代无衬线与优雅衬线字体混合双搭。
