## 四、全局 UI 规范

### 顶部导航（Header）
- PC端：透明吸顶 → 滚动后切换深色背景
- 右上角常驻 **"立即预订"** 按钮（金色描边）
- 多语言切换：ZH / EN / MS
- 移动端：汉堡菜单收纳，全屏抽屉展开

### 底部（Footer）
- Logo + 品牌 Slogan
- 快速链接（所有页面）
- 联系信息：WhatsApp / Email
- 版权声明 + 隐私政策
- 社交媒体入口（待运营提供账号）

### 全局设计语言

#### 色彩系统

| Token | 值 | 用途 |
|-------|----|------|
| `--color-primary` | `#003865` | 仙本那深海蓝，主色；导航、按钮主背景、标题强调 |
| `--color-accent` | `#0091da` | 仙本那天空蓝，辅助色；链接、图标、hover 高亮 |
| `--color-gold` | `#b18b74` | 品牌金色；按钮描边、标题装饰线、分隔线 |
| `--color-cream` | `hsl(60,11%,98%)` ≈ `#fafaf8` | 奶白；全站默认区块底色 |
| `--color-background` | `#ffffff` | 极简亮白；卡片、弹层背景 |
| `--color-villas-bg` | `hsl(210,29%,6%)` ≈ `#0a0f14` | 深邃夜蓝；房型区块沉浸式背景（非纯黑） |
| `--color-muted` | `hsl(210,20%,96%)` | 极浅冰蓝；次级区块、卡片底色 |
| `--color-about-bg` | `hsl(40,21%,96%)` ≈ `#f8f6f1` | 暖米色；酒店介绍区块底色 |

> 区块背景交替原则：奶白 `cream` ↔ 暖米 `about-bg` ↔ 深夜蓝 `villas-bg`，无纯黑。

#### 字体系统

| 角色 | 字体 | 字重 | 典型用途 |
|------|------|------|----------|
| **英文大标题** | Cinzel Variable（`font-serif`） | 600 SemiBold | `h1`/`h2`，全大写碑铭气质，品牌感 |
| **英文正文 / 引言** | Newsreader Variable（`font-sans`） | 400 Regular，`opsz 36` | 段落正文、大号引言、副标题 |
| **中文衬线** | Noto Serif SC（思源宋体） | 400/500/600/700 | 作为 Cinzel / Newsreader 的中文 fallback，同步沿用 |
| `h1~h6` / `.font-serif` | 默认继承 Cinzel + Noto Serif SC | 600 | 所有标题元素全局默认 |
| `body` / `.font-sans` | 默认继承 Newsreader + Noto Serif SC | 400，`opsz 36` | 全站默认正文 |

> 全站启用 `-webkit-font-smoothing: antialiased`，保证苹果设备奢华字重质感。
