## 区块二：预订查询栏（BookingBar）

**形式**：固定在页面顶部（或吸顶），横向排列输入项

**字段设计**

| 字段 | 类型 | 说明 |
|------|------|------|
| 入住日期 | 日期选择器 | 最早可选：2026-10-01 |
| 退房日期 | 日期选择器 | 最短住1晚 |
| 成人人数 | 数字选择 | 默认2人 |
| 儿童人数 | 数字选择 | 5岁及以下免费（共用现有床铺） |
| 套餐类型 | 下拉选择 | 默认"全包套餐" |
| 查询按钮 | CTA | "查看空房 / Check Availability" |

**底部注释**
```
* 入住时间 14:00 / 退房时间 12:00
* 儿童5岁及以下与父母共用床铺免费
* 需额外加床请在备注中说明（按需收费）
```

## 区块五：预订须知

**形式**：可折叠 Accordion 列表（默认全收起，点击展开）

| 标题 | 内容摘要 |
|------|----------|
| 入住 & 退房时间 | 入住 14:00 / 退房 12:00；早入晚出视空房情况，可能额外收费 |
| 支付方式 | 银行转账 / 主流信用卡及借记卡 |
| 定金政策 | 需缴纳定金以确认预订（具体金额见预订确认函） |
| 取消政策 | 提前约定天数可免费取消；部分特惠套餐不可退款；临时取消或不到店将收取费用 |
| 儿童政策 | 5岁及以下与父母共用床铺免费；如需加床另收费 |
| 修改预订 | 需提前至少3天申请，视空房情况处理 |
| 禁止携带宠物 | 为保护岛屿生态，谢绝携带宠物 |
| 禁烟政策 | 仅限指定室外区域吸烟 |
