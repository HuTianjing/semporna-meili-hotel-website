## 六、落地方案

### 组件结构

```
app/[locale]/gallery/
  page.tsx                    ← Server Component，导出静态图片数据

components/gallery/
  GalleryHero.tsx             ← 纯展示，Server Component
  GalleryClient.tsx           ← 'use client'，包含 Tab 筛选 + 网格 + 灯箱
  GalleryFilter.tsx           ← Tab 栏，接收 activeTab / onChange
  GalleryGrid.tsx             ← CSS columns 瀑布流，接收过滤后图片数组
  GalleryLightbox.tsx         ← 全屏灯箱，接收 images + currentIndex
  GalleryCTA.tsx              ← 底部 CTA，Server Component
```

**职责边界**：图片数据静态定义在 `page.tsx`，作为 props 传入 `GalleryClient`；筛选状态、灯箱开关全部收在 `GalleryClient` 内，避免多余的 `useContext`。

---

### 数据结构

```ts
// types/gallery.ts
export type GalleryCategory =
  | 'all' | 'villa' | 'dining' | 'amenities'
  | 'ocean' | 'nature' | 'architecture' | 'culture';

export interface GalleryImage {
  id: string;          // e.g. "V-01"
  src: string;         // /images/gallery/v-01.jpg
  alt: string;         // 无障碍描述
  title: string;       // 中文说明，灯箱展示用
  category: GalleryCategory;
  span?: 'tall' | 'wide' | 'normal'; // 控制瀑布流视觉节奏（可选）
}
```

---

### 关键交互

**Tab 筛选**
```
activeTab === 'all' → 展示全部
activeTab === 'ocean' → filter(img => img.category === 'ocean')
切换 Tab 时：网格淡出 → 重新渲染 → 淡入（Framer Motion AnimatePresence）
```

**瀑布流网格**
```
实现：CSS columns（无需额外依赖）
  columns-2 md:columns-3（移动2列，桌面3列）
  break-inside-avoid 防止图片跨列截断
图片加载：next/image，sizes="(max-width:768px) 50vw, 33vw"
悬停：覆盖半透明深色遮罩 + 图片标题（PC端）
```

**全屏灯箱**
```
依赖：yet-another-react-lightbox（轻量，支持手势/键盘）
触发：点击任意 GalleryGrid 图片
展示：全屏图片 + 底部标题 + 分类 Badge
导航：左右箭头 / 键盘方向键 / 触摸滑动
关闭：右上角 × / 按 Esc
```
