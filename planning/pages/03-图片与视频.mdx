# 图片与视频策划 — Photos & Videos Gallery

> 路由：`/gallery`
> 参考范本：四季波拉波拉酒店（https://www.fourseasons.com/zh/borabora/photos-and-videos/）
> 叙事目的：让访客随着页面向下滚动，完成一次「想象中的抵达」——从第一眼看见这片海，到走进别墅，到沉入珊瑚世界，到举杯落日。图像主导，文字只做情绪锚点。
> 核心原则：**线性叙事滚动，而非 Tab 筛选过滤**。页面是一条叙事河流，每个主题区块是旅程中的一个驿站，访客无需操作，只需向下感受。

---

## 一、设计理念：参考四季波拉波拉的「主题横向沉浸」模式

四季波拉波拉图片页面之所以简洁大方，在于它遵循了三条铁律：

**① 主题分区，线性滚动，无需筛选操作**
页面由「酒店概览 → 服务设施 → 别墅套房 → 餐饮美食」四个主题区块自上而下排列。访客无需点击 Tab、筛选分类，只需向下滚动即可依次感受每一个价值维度。每个主题是叙事旅程中的一个停留节点。

**② 每个主题区块 = 一组横向幻灯片（Carousel）**
每个主题配独立横向图片轮播，每次展示 1 张，左右箭头翻页，图片下方配一句极简标题文字。访客始终感受到「画面扑面而来」，而不是面对密密麻麻的图片墙。

**③ 文字极度克制，只做情绪锚点**
每个主题区块只需：一行主题标题（中/英）+ 每张图一句说明文字（不超过10字）。无介绍段落，无参数列表，图像自己说话。

**美丽度假酒店的差异化应用**：
四季波拉波拉用4个主题，美丽度假酒店差异化卖点更丰富（珊瑚金三角、BELIAN铁木、吉尼斯纪录、星空、海狼风暴……），因此规划 6 个主题区块。每个区块保持「一组横向幻灯片 + 极简文字」的一致结构，不因主题增多而增加复杂度。

## 二、访客情绪弧线

```
Hero 全宽图（第一眼：这片海）
  ↓ 主题一：这片海 · 天光与海色 —— 最强视觉冲击，用玻璃海留住访客
  ↓ 主题二：深入水下 · 珊瑚世界 —— 从海面到海底，彻底激活好奇心
  ↓ 主题三：别墅与居停 —— 美景固然好，住在哪里？BELIAN铁木+露台
  ↓ 主题四：建筑传奇 —— 这不是普通度假村，吉尼斯规模+俯视鸟瞰
  ↓ 主题五：设施与体验 —— 无边泳池/高尔夫/Spa，在这里可以做什么？
  ↓ 主题六：一餐一景 —— 每一刻都值得被记住，米其林+日出咖啡+落日酒吧
```

## 四、Hero 视觉入口

> **不是普通 Hero，是情绪转场。** 无导航按钮、无描述段落，只有一张震撼全幅图与极简文字。

**高度**：`85vh`（移动端），`90vh`（桌面端）

**图片选取**：优先使用天光海色类——玻璃海全景航拍或 360° 日落。要求颜色饱和、层次丰富、无明显主体前景遮挡，让画面自己说话。

**文字叠层**（居中绝对定位，垂直居中）：

```
行 1（font-serif，clamp(2rem, 5vw, 4.5rem)，text-white/85，tracking-[0.05em]）：
  一半秘境，一半海洋

行 2（font-sans，text-xs，text-white/45，tracking-[0.45em]，uppercase，mt-4）：
  MEILI RESORT HOTEL · SEMPORNA · 4°N · CORAL TRIANGLE
```

**渐变遮罩**：`bg-gradient-to-b from-black/15 via-transparent to-black/65`
底部渐变衔接第一个主题区块的背景色（`bg-cream`），无生硬断层。

**向下滚动提示**（底部居中，绝对定位）：向下箭头 icon，`text-white/35`，轻微上下浮动动画。

## 五、主题区块规范（六个区块共用）

每个主题区块结构完全一致，通过 props 差异化：

### 5.1 区块结构

```
┌─────────────────────────────────────────────────────┐
│  章节序号 + 主题标签（中/英）                          │
│  ─────── 金色装饰线 ───────                           │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │  横向幻灯片图片区（全宽，aspect-[16/9] 桌面端）  │   │
│  │  左右箭头  ·  当前 X / 共 N 张               │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  图片标题文字（当前张，居中，极简）                     │
└─────────────────────────────────────────────────────┘
```

### 5.2 视觉规范

**区块背景**：交替使用 `bg-cream` 与 `bg-background`（纯白），细微交替感知分区，无斑马纹震动感。

**章节标签**（每个主题区块顶部，居中对齐）：
序号（金色微字）+ 竖线分隔 + 主题中文名 + 英文副标签。

**幻灯片图片区**：
- 桌面：`aspect-video`（16:9），全宽 `w-full`
- 移动：`aspect-[4/3]`，全宽
- `object-fit: cover`，`object-position: center`
- 图片切换动效：`opacity` 渐变（0→1，200ms），无位移滑动。

**左右导航箭头**：
- 桌面：悬浮于图片两侧边缘，居中垂直对齐。
- 背景：全黑色带透明度，悬浮时加深。

**图片计数器**（图片区正下方，居中）：
例如：`01 / 07`

**图片标题文字**（计数器下方，居中，主要情绪锚点）：
例如：`玻璃海全景 · 北纬四度的碧蓝`

**垂直间距**：`py-16 sm:py-20 md:py-28`，上下对称。

## 十、组件结构与数据规范

### 10.1 目录结构

```
app/[locale]/gallery/
  page.tsx                 ← Server Component，定义图片数据，渲染所有区块
components/gallery/
  GalleryHero.tsx          ← Server Component，全宽视觉入口
  GalleryTheme.tsx         ← Client Component，横向幻灯片区块
  GalleryVideo.tsx         ← Server Component，视频区块（含占位态）
  GalleryCTA.tsx           ← Server Component，底部行动出口
```

## 一、设计理念：参考四季波拉波拉的「主题横向沉浸」模式

四季波拉波拉图片页面之所以简洁大方，在于它遵循了三条铁律：

**① 主题分区，线性滚动，无需筛选操作**
页面由「酒店概览 → 服务设施 → 别墅套房 → 餐饮美食」四个主题区块自上而下排列。访客无需点击 Tab、筛选分类，只需向下滚动即可依次感受每一个价值维度。每个主题是叙事旅程中的一个停留节点。

**② 每个主题区块 = 一组横向幻灯片（Carousel）**
每个主题配独立横向图片轮播，每次展示 1 张，左右箭头翻页，图片下方配一句极简标题文字。访客始终感受到「画面扑面而来」，而不是面对密密麻麻的图片墙。

**③ 文字极度克制，只做情绪锚点**
每个主题区块只需：一行主题标题（中/英）+ 每张图一句说明文字（不超过10字）。无介绍段落，无参数列表，图像自己说话。

**美丽度假酒店的差异化应用**：四季波拉波拉用4个主题，美丽度假酒店差异化卖点更丰富（珊瑚金三角、BELIAN铁木、吉尼斯纪录、星空、海狼风暴……），因此规划 6 个主题区块。每个区块保持「一组横向幻灯片 + 极简文字」的一致结构，不因主题增多而增加复杂度。
