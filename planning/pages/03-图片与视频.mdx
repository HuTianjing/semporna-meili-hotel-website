# 图片与视频策划 — Photos & Videos Gallery

> 路由：`/gallery`
> 参考范本：四季波拉波拉酒店（https://www.fourseasons.com/zh/borabora/photos-and-videos/）
> 叙事目的：让访客随着页面向下滚动，完成一次「想象中的抵达」——从第一眼看见这片海，到走进别墅，到沉入珊瑚世界，到举杯落日。图像主导，文字只做情绪锚点。
> 核心原则：**线性叙事滚动，而非 Tab 筛选过滤**。页面是一条叙事河流，每个主题区块是旅程中的一个驿站，访客无需操作，只需向下感受。

---

## 一、设计理念：参考四季波拉波拉的「主题横向沉浸」模式

四季波拉波拉图片页面之所以简洁大方，在于它遵循了三条铁律：

**① 主题分区，线性滚动，无需筛选操作**
页面由「酒店概览 → 服务设施 → 别墅套房 → 餐饮美食」四个主题区块自上而下排列。访客无需点击 Tab、筛选分类，只需向下滚动即可依次感受每一个价值维度。每个主题是叙事旅程中的一个停留节点。

**② 每个主题区块 = 一组横向幻灯片（Carousel）**
每个主题配独立横向图片轮播，每次展示 1 张，左右箭头翻页，图片下方配一句极简标题文字。访客始终感受到「画面扑面而来」，而不是面对密密麻麻的图片墙。

**③ 文字极度克制，只做情绪锚点**
每个主题区块只需：一行主题标题（中/英）+ 每张图一句说明文字（不超过10字）。无介绍段落，无参数列表，图像自己说话。

**美丽度假酒店的差异化应用**：
四季波拉波拉用4个主题，美丽度假酒店差异化卖点更丰富（珊瑚金三角、BELIAN铁木、吉尼斯纪录、星空、海狼风暴……），因此规划 6 个主题区块。每个区块保持「一组横向幻灯片 + 极简文字」的一致结构，不因主题增多而增加复杂度。

```
Hero 全宽图（第一眼：这片海）
```

## 四、Hero 视觉入口 (`GalleryPageHeader`)

> **不再依靠巨幅底图，而是通过极简留白的排版设计给页面奠定呼吸感。**

**高度**：占满屏幕顶部空间（配合大字体和留白排版）

**排版设计**：
- 左侧布局或居中排版，基于多语言通过 `next-intl` 获取文案。
- “一半秘境，一半海洋”(Half Sanctuary, Half Ocean) —— 使用响应式巨型字体。
- 副标题显示项目坐标与调性：`MEILI RESORT HOTEL · SEMPORNA · 4°N · CORAL TRIANGLE`。

**滚动提示**：
在此区域下方直接衔接画廊的第一篇章。不再需要显式的渐变和按钮，只要一滚动，整屏幕就会滑向 GSAP 控制的动态画廊世界中。

## 五、主题区块规范 (`GalleryGSAPShowcase`)

这不仅仅是六个独立的区块，而是同一个交互系统里的六幕剧。

### 5.1 交互与动效结构 (Desktop)

```text
┌─────────────────────────────────────────────────────┐
│  (左侧，宽度占 35%-45%, 粘性锁定 Pin)                  │
│                                                     │
│   章节序号 (01/06)   —    主体中英标签                │
│   -------------------------------------------       │
│                                                     │
│   当前图片标题 (SplitChars 逐字出场)                  │
│   说明副文案 (SplitChars 逐字出场，带透明度)              │
│                                                     │
│                                                     │
│  (右侧，宽度占余下大半区, 图片向上滚动)                  │
│                                                     │
│   图片A (index 0) 默认展示                            │
│   ↓                                                 │
│   滚动时，图片B (index 1) clip-path: inset(100% 0 0)    │
│   变为 inset(0 0 0 0)，模拟「向上覆盖揭开」视觉          │
│   同时，左侧文字淡出，替换为图片B的文案，重新逐字浮现。      │
└─────────────────────────────────────────────────────┘
```

### 5.2 视觉与技术特征

**双色交替**：
六大 `ChapterSection` 的背景色（例如 `--about-bg`, `--secondary`, `--background` 等等）应在视觉上形成呼吸感，比如「暖白、深色、暖白、浅灰...」交替。

**文字动效（GSAP Stagger）**：
- 进入区块时：主标题、副标题、分隔线整体入场。
- 换图时：图片左侧配合的标题、文案，通过 `<SplitChars>` 组件拆分成字母，利用 GSAP stagger 进行阶梯式浮现。

**图片展现形式**：
- 全宽满屏（覆盖右侧专区）。利用 `object-cover` 和优化的 `<Image>` 并发加载。
- 不需要额外边框，图片的「边缘」就是揭开效果的锋利切割线。

**移动端适配 (Stacking 降级)**：
- 对于 `< 1024px` 的屏幕，关闭 ScrollTrigger 锁定机制。
- 让每张图片和文字退化成为常规的瀑布流卡片堆叠（常规纵向滚动）。利用 `Intersect Observer` 或 ScrollTrigger 基础视差在靠近视口时触发简单的 `fade-up` 即可。

## 十、组件结构与数据规范

### 10.1 目录结构

```text
app/[locale]/gallery/
  page.tsx                 ← Server Component，获取所有翻译数据并渲染以下区块
components/gallery/
  GalleryPageHeader.tsx    ← Server Component，留白式全宽视觉入口
  GalleryGSAPShowcase.tsx  ← Client Component，核心 GSAP 视差组件，循环渲染所有 Chapter
  GalleryVideo.tsx         ← Server Component，视频区块（目前处于全幅图像占位态）
  GalleryCTA.tsx           ← Client Component，带 Framer Motion 动效的底部行动出口
```

## 一、设计理念：Cinematic Plunge Gallery 视差沉浸联动滚动

为打造最具视觉冲击力的「沉浸感」，摒弃了传统的点击 Tab 和横向 Carousel 幻灯片，而是采用基于 GSAP + ScrollTrigger 的联动视差滚动（Pin & Reveal）：

**① 主题分区，强绑定线性阅读，无需筛选操作**
页面由六个主题自上而下排列。在桌面端向下滚动时，屏幕自动进入「锁定 (Pin)」状态，强制用户沉浸在这个主题的叙事空间中。

**② 左侧文案锁定，右侧图像由下而上揭开 (Clip-path Reveal)**
不再使用横滑。在同一主题内：
- 屏幕左侧固定显示当前主题名称与单张图片的说明文案（随滚动逐字浮现、淡入淡出更替）。
- 屏幕右侧为一整面图片堆叠区。随着鼠标滚轮向下，图片像画卷一样从下至上利用 `clip-path: inset(100% 0% 0% 0%)` 被一点点「揭开」，覆盖上一幅画面。
- 保证访客始终感受到「全新画面如潮水般扑面而来」，每一张大图均满屏呈现。

**③ 移动端优雅降级 (Stack & Scroll)**
在手机等窄屏设备上取消锁定效果，降级为常规的全屏图片依次堆叠显示，配合文字浮现淡入动效，保证小屏操作顺滑自然。
