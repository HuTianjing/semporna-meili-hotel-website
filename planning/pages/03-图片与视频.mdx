# 图片与视频策划 — Photos & Videos Gallery

> 路由：`/gallery`
> 叙事目的：让访客在看图的过程中，完成一次"想象中的入住"——从落地这片海，到走进别墅，到沉入水下，到仰望星空。
> 核心原则：图像是唯一主角，UI 是容器。每一张图片都在回答一个问题：**为什么值得来这里？**

---

## 一、访客旅程与情绪弧线

图库不是资料库，是一段叙事。访客打开这个页面时，心里的问题不是"你们有什么图"，而是 **"我去了之后会是什么感受？"**

页面的情绪弧线应当是：

```
页面入口（落地这片海的第一眼）
  ↓
分类浏览（按自己最在意的卖点深入）
  ↓
灯箱沉浸（放大一张图，与这片海独处片刻）
  ↓
视频（如果有）→ 最强的情绪放大器
  ↓
底部出口（从向往转化为行动）
```

Tab 分类不按通用酒店模板（外观/餐饮/设施），而是**围绕差异化价值主张**重新组织，让每个 Tab 的名字本身就在传递一个理由：

| Tab 标签 | 英文副标题 | 传递的核心理由 |
|---------|-----------|--------------|
| 全部 | All | 整体印象 |
| 别墅与居停 | Villa & Stay | BELIAN铁木、180°海景露台、管家服务 |
| 一餐一景 | Dining & Views | 米其林、日出咖啡、落日酒吧、全包 |
| 无尽设施 | Amenities | 无边泳池、高尔夫、Spa、剧场、儿童乐园 |
| 深入海洋 | Ocean & Diving | 珊瑚金三角、海狼风暴、海龟、崖壁 |
| 天光与海色 | Sky & Sea | 玻璃海、360°日出日落、银河星空 |
| 建筑传奇 | Architecture | 吉尼斯规模、BELIAN纹理、别墅群鸟瞰 |
| 这片海的人 | Culture | 巴瑶族、码头、渔船、人文温度 |

## Intro：视觉入口

> **不是 Hero，是情绪转场。** 无大标题，无按钮，只有一张震撼的图与三个字。

**高度**：`60vh`（移动端），`70vh`（桌面）

**图片选择**：优先使用天光海色类——玻璃海全景航拍（N-01）或 360° 日落（N-03）。要求颜色饱和、层次丰富、无明显主体，让画面自己说话。

**文字叠层**（居中，极简）：
```
字 1（font-serif，极大，text-white，低透明度 text-white/80）：
  一半秘境，一半海洋
  Part Hidden Sanctuary · Part Endless Ocean

字 2（font-sans，text-xs，text-white/40，tracking-[0.4em]，uppercase）：
  MEILI RESORT HOTEL · SEMPORNA · 4°N
```

**渐变遮罩**：`bg-linear-to-b from-black/20 via-transparent to-black/60`（下方过渡到 Tab 栏背景色）

**向下箭头**（可选）：底部居中，`ChevronDown`，`text-white/30`，轻微呼吸动画

## 区块 A：分类 Tab 筛选栏

**背景色**：`bg-[--color-villas-bg]`（深夜蓝，与 Intro 底部渐变无缝衔接）

**Tab 样式**：
- 文字：`font-sans text-xs uppercase tracking-[0.25em] text-white/40`
- 激活态：`text-white border-b border-gold pb-2`（金色底线，不用背景色块）
- 非激活 hover：`text-white/70`

**移动端**：横向滚动（`overflow-x-auto`，`snap-x snap-mandatory`），隐藏滚动条，最左侧留 `pl-6` 暗示可滑动

**桌面端**：居中展开，Tab 间距 `gap-8 lg:gap-12`

**Tab 顺序**（按情绪递进，而非分类字母序）：
```
全部 → 天光与海色 → 别墅与居停 → 深入海洋 → 建筑传奇 → 一餐一景 → 无尽设施 → 这片海的人
```

> 为什么这个顺序？"天光与海色"是打动人的第一眼（仙本那最直接的视觉冲击），"这片海的人"是情感收尾，两头锚定整个体验弧线。

## 区块 B：瀑布流图片网格

**布局**：CSS columns（无额外依赖）
```
columns-2 md:columns-3
gap-1 md:gap-2
break-inside-avoid（防跨列截断）
```

**图片比例节奏**（`span` 字段控制）：
- `normal`：自然比例，图片自适应
- `tall`：纵版图（`aspect-[3/4]`），适合别墅室内、人物特写
- `wide`：横版图（`aspect-video`），适合海景全景、建筑鸟瞰

> 建议每 6 张图片中至少包含 1 张 `wide` 或 1 张 `tall`，避免视觉单调。

**图片加载**：`next/image`，`sizes="(max-width:768px) 50vw, 33vw"`，`loading="lazy"`（Intro 图除外，需加 `priority`）

**PC端 Hover**：
```
图片区域覆盖半透明遮罩（bg-black/0 → bg-black/50，duration-300）
底部滑入图片标题（font-sans text-xs text-white tracking-[0.2em]，translateY(100%) → 0）
```

**移动端**：无 hover，点击直接打开灯箱

**空状态占位**（某分类图片尚未交付时）：
```
占位格：bg-[--color-villas-bg]，宽度与正常图片相同
中央放：锁形图标（text-white/20）+ "即将揭幕 · Coming Soon"（text-white/20 text-xs）
占位格数量：不少于 3 个，保持网格视觉密度
```

## 五、落地方案

### 组件结构

```
app/[locale]/gallery/
  page.tsx                    ← Server Component，静态定义图片数据，传入 GalleryClient

components/gallery/
  GalleryIntro.tsx            ← 视觉入口，Server Component（静态全宽图 + 极简文字）
  GalleryClient.tsx           ← 'use client'，Tab 筛选 + 网格 + 灯箱状态管理
  GalleryFilter.tsx           ← Tab 栏，接收 activeTab / onChange / tabs 配置
  GalleryGrid.tsx             ← CSS columns 瀑布流，接收过滤后图片数组
  GalleryLightbox.tsx         ← 全屏灯箱，接收 images + currentIndex + onClose
  GalleryVideo.tsx            ← 视频区块，Server Component（含占位态）
  GalleryCTA.tsx              ← 底部 CTA，Server Component
```

**职责边界**：图片数据静态定义在 `page.tsx`，作为 props 传入 `GalleryClient`；Tab 筛选状态、灯箱开关全部收在 `GalleryClient` 内，不使用 `useContext`。`GalleryIntro`、`GalleryVideo`、`GalleryCTA` 均为 Server Component，无需 `'use client'`。

---

### 数据结构

```ts
// types/gallery.ts
export type GalleryCategory =
  | 'all' | 'villa' | 'dining' | 'amenities'
  | 'ocean' | 'nature' | 'architecture' | 'culture';

export type GallerySpan = 'tall' | 'wide' | 'normal';

export interface GalleryImage {
  id: string;                 // e.g. "V-01"
  src: string;                // /images/gallery/v-01.jpg
  alt: string;                // 无障碍描述（必填，有意义）
  title: string;              // 中文说明，灯箱展示用
  category: GalleryCategory;
  span?: GallerySpan;         // 控制瀑布流视觉节奏
}

export interface GalleryTab {
  key: GalleryCategory;
  label: string;              // 中文标签
  labelEn: string;            // 英文副标签
}
```

---

### 关键交互细节

**Tab 切换动效**
```
切换时：
  1. 当前网格 opacity: 1 → 0（duration 150ms）
  2. 重新过滤数组，渲染新网格
  3. 新网格 opacity: 0 → 1（duration 200ms）
使用 Framer Motion AnimatePresence + key={activeTab} 实现
```

**图片懒加载顺序**
```
首屏可见图片（前6张）：loading="eager" priority
其余图片：loading="lazy"（浏览器原生）
```

**灯箱键盘无障碍**
```
ArrowLeft / ArrowRight → 上/下一张
Escape → 关闭灯箱
Tab → 焦点在灯箱内循环（关闭按钮 → 左箭头 → 右箭头）
```
