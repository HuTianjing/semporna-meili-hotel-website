## 区块二：联系表单

**形式**：简洁表单，字段不超过6个，避免用户填写疲劳

**字段设计**

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 姓名 / Name | 文本 | ✅ | 中英文均可 |
| 联系邮箱 / Email | 邮件 | ✅ | 回复接收地址 |
| 联系电话 / Phone | 电话 | 可选 | 含国家区号 |
| 咨询类型 | 下拉选择 | ✅ | 见下方分类 |
| 预计入住日期 | 日期 | 可选 | 仅预订相关时显示 |
| 详细信息 / Message | 多行文本 | ✅ | 最多500字 |

**咨询类型下拉选项**
```
- 预订咨询 / Reservation Enquiry
- 套餐与优惠 / Packages & Offers
- 接送安排 / Transfer Arrangement
- 蜜月/特殊庆典安排 / Honeymoon & Celebrations
- 其他 / Others
```

**提交按钮**：发送消息 / Send Message

**提交后提示**
```
成功提示：
感谢您的联系！我们将在24小时内通过邮件或电话与您取得联系。
如需立即回复，请通过 WhatsApp 联系我们：+6011 2780 3997
```

> ⚠️ **技术说明**：表单提交可通过 Server Action + 邮件服务（如 Resend / Nodemailer）实现，或暂时引导至 WhatsApp 替代。

### 分类三：政策与设施

**Q8：取消政策是什么？**
```
A：免费取消须在抵达前约定天数内提出（具体见您的预订条款）。

部分特惠套餐（如全包套餐）不可退款，须全额预付。
```

**Q9：是否包含餐食？**
```
A：全包套餐包含每日早餐、午餐、晚餐及下午茶（2人份）。
您可完全放松，由我们的厨师团队为您精心准备每一餐。
具体以您的预订套餐条款为准。
```

**Q10：是否提供 Wi-Fi？**
```
A：是的，公共区域及别墅内均提供免费 Wi-Fi，
让您可以随时分享这段美好旅程。
```

**Q11：吸烟政策？**
```
A：为保护纯净的自然环境及所有宾客的舒适体验，
```
