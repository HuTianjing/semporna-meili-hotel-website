# 位置策划 — Location Page

> 路由：`/location`
> 目标：消除"如何到达这个偏远岛屿"的顾虑，将交通流程可视化，同时唤起对这片海的向往

---

## 设计思路

这个页面要解决一个隐性焦虑：**仙本那很远，我能到达吗？**

答案不是甩给访客一张时刻表，而是让他们在页面上已经完成了一次想象中的抵达。他们读完这个页面，应该感受到的是：这片海值得去，而且我完全不需要担心怎么去，有人替我想好了。

页面分三层叙事，由浅入深：
1. **为什么是这里** — 地理稀缺性 + 人文温度，建立向往
2. **我需要知道什么** — 套餐已含、价格透明、行前准备，建立安心
3. **我怎么到达** — 全程接送路线 + 班次时刻，建立信心

---

```
┌─────────────────────────────────────────────────────┐
│  主导航 Header（全局 sticky，h-17/sm:h-20）           │
├─────────────────────────────────────────────────────┤
│  副导航 — bg-primary sticky top-17/sm:top-20         │  ← 直接衔接，无独立 Page Header
│  ┌─────────────────────────────────────────────┐   │
│  │   地方人文   ｜   须知信息   ｜   交通指引      │   │
│  └─────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────┤
│  区段一：地方人文  id="location-culture"              │
│  bg-primary                                         │
├─────────────────────────────────────────────────────┤
│  区段二：须知信息  id="location-info"                 │
│  bg-[--color-about-bg]                              │
├─────────────────────────────────────────────────────┤
│  区段三：交通指引  id="location-transport"            │
│  bg-primary                                         │
└─────────────────────────────────────────────────────┘
```

**无独立 Page Header**：副导航直接紧贴主导航底部，不做额外的标题区块。页面大标题融入区段一开篇，让第一屏就进入实质内容。

**颜色逻辑**：副导航 + 区段一（深海蓝）→ 区段二（暖米色，对比节奏）→ 区段三（深海蓝，收尾 + CTA）

---

## 副导航（`LocationSubNav.tsx`，`'use client'`）

**设计意图**：参考奢华酒店的页内索引形式——干净、克制、不抢戏。访客快速定位内容，不需要猜。

**视觉规范**：
- 背景：`bg-primary`，与 Header 和深色 Section 完全一体，无分割线感
- 边框：`border-b border-white/10`（极细，仅用于与正文区分）
- 粘性：`sticky top-17 sm:top-20 z-40`（直接顶到主导航底部，无额外留白）
- 内边距：`py-3 sm:py-4 px-page`，高度克制，不抢占正文空间

**Tab 布局**：

```
[  地方人文  ]  ｜  [  须知信息  ]  ｜  [  交通指引  ]
```

- 三个 Tab 居中排列，`flex justify-center items-center gap-6 sm:gap-10`
- 分隔符 `｜`：`text-white/20`，`mx-1 sm:mx-2`，`select-none`，非按钮
- **激活态**：`text-[--color-gold-warm]`，无下划线，无背景，无边框——仅靠颜色区分
- **非激活态**：`text-white/50 hover:text-white/80`
- Tab 文字：`font-sans text-[0.65rem] sm:text-[0.7rem] uppercase tracking-[0.25em]`
- 中英双行可选：主行中文，英文小字在下方（`text-[0.5rem] text-white/30`）

**交互逻辑**：
- 点击：平滑滚动至对应 Section，偏移量 = 主导航高度 + 副导航高度（约 108px mobile / 128px desktop）
- 滚动同步：`IntersectionObserver` 监听三个 section，`rootMargin: '-80px 0px -40% 0px'`，进入视口即切换激活 tab

## 区段一：地方人文（`LocationCulture.tsx`）

**背景色**：`bg-primary` — 深海蓝沉浸式，紧接副导航，形成整体门廊感  
**顶部内边距**：`pt-16 sm:pt-24 md:pt-36 lg:pt-44`（副导航已占位，正文从此处开始）  
**底部内边距**：`pb-16 sm:pb-24 md:pb-36 lg:pb-44`

> 区段一是整个页面的第一块内容，副导航之后直接进入。页面坐标标题（北纬 4°）不单独作为 Header 呈现，而是融入 1-A 的章节引言，由正文承载地理定位信息。

### 1-A 地理优势

**布局**：桌面端左图右文（各占约 50%），移动端图在上、文在下  
**图片**：全高海洋摄影（如 iStock-831459576.jpg），`object-cover`，左侧铺满，`aspect-[3/4] md:aspect-auto`

**章节标签**：`01 · THE LOCATION · 绝世位置`  
**主标题**：珊瑚金三角的中心

文字内容（右侧，三段）：

> 美丽度假酒店坐落于马来西亚仙本那的玻璃海之上，北纬 4° 至 5°，赤道附近。全年气温 26° 至 32°，是热带度假的理想温度。

> 仙本那受菲律宾棉兰老岛与加里曼丹岛双重遮蔽，是台风路径的天然盲区，过去百年从未遭受台风侵袭。"风下之乡"——这片海，是地球上最安全、最宁静的角落之一。

> 这里与全球公认的顶级潜水圣地诗巴丹岛（Sipadan）比邻而居，陡峭的海底悬崖与壮观的海洋生物，令无数潜水爱好者毕生向往。

**地理数据亮点（4格横向网格）**，位于文字段落正下方：

| 数值 | 中文说明 | 英文说明 |
|------|---------|---------|
| `4°N` | 北纬四度 · 赤道海域 | 4° North Latitude |
| `26–32°C` | 全年舒适气温 | Year-round Temperature |
| `100+ 年` | 无台风记录 | 100+ Years Typhoon-Free |
| `< 30 分钟` | 快艇直达诗巴丹 | Speedboat to Sipadan |

数字用 `font-serif clamp(2rem, 3vw, 2.8rem) text-white`，说明用 `font-sans text-[0.6rem] text-white/50`。

### 1-B 巴瑶族 — 人文温度

**布局**：与 1-A 左右互换（图在右，文在左），保持视觉节奏  
**图片**：巴瑶族生活摄影（现为占位图），`object-cover`

**章节标签**：`02 · THE BAJAU PEOPLE · 巴瑶族`  
**主标题**：世代守护这片海的人

文字内容（左侧，两段）：

> 巴瑶族（Bajau），被称为「海上游牧民族」，世代居于仙本那这片海域。他们生于海上，长于海上，以自由潜水为生，与这片珊瑚礁和谐共生已逾千年。

> 他们是这片海洋最深情的守护者，也是这片大海最动人的名片。在美丽度假酒店，您将有机会聆听这段人与大海的千年故事。

## 区段二：须知信息（`LocationNeedToKnow.tsx`）

**背景色**：`bg-[--color-about-bg]` — 暖米色，与深海蓝形成节奏对比  
**竖向间距**：`py-16 sm:py-24 md:py-36 lg:py-44`

### 布局方案

桌面端双列：
- **左列**（约 55%）：套餐已含 + 行前准备清单
- **右列**（约 45%）：预订须知（价格突出 + 政策条款）

移动端：左列在上，右列在下。

### 左列：套餐已含 + 行前清单

**章节标签**：`01 · INCLUDED · 套餐已含`  
**主标题**：全包套餐，已为您备妥

套餐清单（带金色勾选图标，非普通 bullet）：

- 每日三餐 + 下午茶（2人）
- 塔瓦机场 ⇄ 仙本那码头（专属车辆）
- 仙本那码头 ⇄ 酒店（专属快艇）
- 礁石区潜水 / 浮潜体验
- 无边泳池 · 海上健身房
- 24小时专属管家服务

**章节标签**：`BUTLER'S NOTE · 管家手记`（与套餐已含同列，下方紧接）  
**主标题**：行前准备清单

清单（同样带勾选图标）：
- 护照或身份证件
- 预订确认函（截图即可，我们已有记录）
- 个人常用药物
- 泳衣（数套）+ 防晒霜（推荐珊瑚友好型）
- 防滑鞋（快艇甲板）+ 墨镜 · 遮阳帽
- 水下摄影装备（可选）

收笔（引言斜体）：岛上一切已为您备妥，轻装出发即可。

### 右列：预订须知

**章节标签**：`02 · BOOKING POLICY · 预订须知`

**价格大字**（视觉焦点）：
```
RM 5,800
/ 晚，2人含税净价
```
价格用 `font-serif clamp(2.2rem, 4vw, 3.5rem) text-[--color-section-text]`，单位说明用 `text-sm text-[--color-warm-text]`。

政策条款（三行，带分割线）：
- 不可退款，需全额预付
- 有效期：2026年10月起
- 套餐不含：水疗 · 酒吧及其他特别注明项目

## 区段三：交通指引（`LocationTransport.tsx`）

**背景色**：`bg-primary` — 深海蓝，与区段一呼应，形成首尾沉浸感  
**竖向间距**：`py-16 sm:py-24 md:py-36 lg:py-44`

### 3-A 到达路线图

**布局**：居中单列，`max-w-2xl mx-auto`，移动端与桌面端相同（垂直时间轴不做横向版）

**设计意图**：时间轴的「边界」本身就是最重要的信息——访客只需到达马来西亚，此后由我们全程安排。这个边界必须在视觉上被清晰感知。

**结构**（从上至下）：

```
章节标签：04 · GETTING HERE · 交通指引
主标题：一段有人等候您的旅程

─────────── 您自行安排 ───────────

[ 机场图标 ]  塔瓦机场（TWU）
              推荐航线：吉隆坡 / 亚庇直飞

─────── 以下由美丽度假酒店全程安排 ────

[ 车辆图标 ]  塔瓦机场 → 仙本那码头          约 1 小时
              专属车辆接送  ✓ 已含

[ 快艇图标 ]  仙本那码头 → 美丽度假酒店      约 30 分钟
              专属快艇  ✓ 已含

[ 定位图标 ]  美丽度假酒店
              Meili Resort Hotel · 仙本那玻璃海
```

- 时间轴线：`w-px bg-[--color-gold-warm]/30`
- 节点圆圈：`border border-[--color-gold-warm]`，图标颜色 `text-[--color-gold-warm]`
- "以下由我们安排"分割线：金色线 + 文字标签，视觉权重明显

**承诺引言**（时间轴下方居中斜体）：

> "自塔瓦机场起，我们的团队将全程陪同您完成剩余旅程。每一段换乘，都有我们的人在等候您。"

### 3-B 班次时刻表

**布局**：桌面端左右双列（到达 / 离开），中间竖向分割线；移动端上下堆叠

**章节标签**：`05 · TRANSFER SCHEDULE · 班次时刻`

| 方向 | 行程 | 班次一 | 班次二 |
|------|------|--------|--------|
| 到达 | 塔瓦机场 → 仙本那码头 | 08:30 | 10:30 |
| 到达 | 仙本那码头 → 美丽度假酒店 | 10:00 | 12:30 |
| 离开 | 美丽度假酒店 → 仙本那码头 | 11:00 | 13:30 |
| 离开 | 仙本那码头 → 塔瓦机场 | 12:00 | 14:30 |

时刻数字：`font-serif text-white text-lg sm:text-xl`，路线说明：`font-sans text-white/70 text-sm`

**时刻表下方三条提示**（以「我们」为主语，承诺语气）：
1. 我们将在您抵达塔瓦机场后，安排专属司机在出口处等候
2. 如您的航班时间特殊，请提前联系我们，我们将灵活调整接送安排
3. 所有接送行程均已含于套餐，无需额外支付

### 3-C 底部 CTA

**位置**：区段三最底部，即整个页面的结束处  
**语气**：主动承诺，不是"需要帮助吗"

分割线 → 主标题 → 英文副标题 → 描述 → 双按钮

**主标题**：您的旅程，从预订那一刻起由我们来安排  
**英文副标题**：*Your Journey Begins the Moment You Book*  
**描述**：告诉我们您的航班信息，我们的管家团队将立即着手为您安排全程接送。

**按钮一（主）**：WhatsApp 发送航班信息 → `wa.me/601127803997`（金色实底）  
**按钮二（次）**：发送邮件 → `amy@meilihotel.com`（金色描边）
