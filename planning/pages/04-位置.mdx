## 区块二：到达路线图

**形式**：全端统一的垂直卡片堆叠，不做桌面横向版。

> **为什么放弃横向步骤图？**
> 横向排版在移动端字体被迫缩到极小，连接线和节点文字挤压严重，与品牌的「大留白、大字号」原则相悖。垂直卡片每个节点独立成块，字号自由，在所有屏幕尺寸上保持可读性。

### 两区段设计：边界线是核心信息

路线图在视觉上分成两段，边界本身就是最重要的信息——**访客只需要到达马来西亚，其余的，由我们来。**

```
┌──────────────────────────────────────────┐
│  您自行安排                              │
│                                          │
│  ✈  任意马来西亚机场                    │
│     （推荐经塔瓦 TWU 直飞）             │
└───────────────────┬──────────────────────┘
                    │
        ── 以下由美丽度假酒店全程安排 ──
                    │
┌───────────────────▼──────────────────────┐
│  🚗  塔瓦机场 → 仙本那码头              │
│      专属车辆接送  ·  约 1 小时          │
├──────────────────────────────────────────┤
│  ⛵  仙本那码头 → 美丽度假酒店          │
│      专属快艇  ·  约 30 分钟             │
├──────────────────────────────────────────┤
│  ★  美丽度假酒店（Meili Resort Hotel）  │
└──────────────────────────────────────────┘
```

**每个节点卡片的内容结构**

| 层级 | 内容 | 排版 |
|------|------|------|
| 图标 | Plane / Car / Ship / Star | `text-[--color-gold-warm]`，28px |
| 地点大字 | 塔瓦机场（Tawau, TWU） | `font-serif clamp(1.2rem, 2.5vw, 1.8rem)` |
| 交通方式标签 | 专属车辆接送 | `font-sans text-xs tracking-widest uppercase text-[--color-warm-text]` |
| 时长 | 约 1 小时 | 金色小字，与地点形成对比 |
| 承诺标记 | ✓ 含在全包套餐内 | 金色 checkmark，仅在酒店接管段显示 |

**主动承诺配文**

```
— 您只需要到达马来西亚 —
自塔瓦机场起，我们的团队将全程陪同您完成剩余旅程。
每一段换乘，都有我们的人在等候您。
```

## 区块三：班次时刻表

**形式**：清晰的双向时刻表格，配图标区分"到达"与"离开"方向

### 到达方向（Arrival）

| 行程 | 班次一 | 班次二 |
|------|--------|--------|
| 🚗 塔瓦机场 → 仙本那码头（陆路） | **08:30** | **10:30** |
| ⛵ 仙本那码头 → 美丽度假酒店（快艇） | **10:00** | **12:30** |

### 离开方向（Departure）

| 行程 | 班次一 | 班次二 |
|------|--------|--------|
| ⛵ 美丽度假酒店 → 仙本那码头（快艇） | **11:00** | **13:30** |
| 🚗 仙本那码头 → 塔瓦机场（陆路） | **12:00** | **14:30** |

**班次下方的主动承诺文字**（取代 ⚠️ 警示语气）

```
· 以上为入住与退房当日的专属接送班次
· 请在抵达 3 天前告知我们您的航班信息，我们将提前安排专人等候
· 若遇航班延误或变更，随时联系我们——我们会灵活协调，不让您在码头等待
```

> **语气说明**：三句话主体都是「我们」，而不是「请您……否则……」。前者是承诺，后者是规则告示。
